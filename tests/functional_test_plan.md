# План функционального тестирования vclient

## Условия тестирования

- Клиент запускается в Linux.
- Для позитивных проверок запущен совместимый сервер.
- Подготовлены корректные учётные данные и файл с тестовыми векторами.
- Ожидаемые результаты для позитивных проверок заранее рассчитаны по операции сервера.

| № | Проверка | Тип | Ожидаемый результат |
|---|---|---|---|
| 1 | Запуск без параметров | Позитивный | Выводится справка, программа завершается без ошибки. |
| 2 | Запуск с параметром `-h` | Позитивный | Выводится справка, программа завершается без ошибки. |
| 3 | Запуск без обязательного адреса сервера | Негативный | Выводится диагностическое сообщение; программа завершается с ошибкой. |
| 4 | Запуск без имени входного файла | Негативный | Выводится диагностическое сообщение; программа завершается с ошибкой. |
| 5 | Запуск без имени выходного файла | Негативный | Выводится диагностическое сообщение; программа завершается с ошибкой. |
| 6 | Передача некорректного номера порта | Негативный | Выводится сообщение о некорректном порте; программа завершается с ошибкой. |
| 7 | Передача неизвестного параметра | Негативный | Выводится сообщение о неизвестном параметре; программа завершается с ошибкой. |
| 8 | Указан несуществующий входной файл | Негативный | Выводится сообщение об ошибке открытия файла; соединение с сервером не выполняется. |
| 9 | Входной файл обрезан или содержит некорректную структуру | Негативный | Выводится сообщение об ошибке чтения; программа завершается с ошибкой. |
| 10 | Сервер недоступен по указанному адресу или порту | Негативный | Выводится сообщение об ошибке соединения; программа завершается с ошибкой. |
| 11 | Указаны неверные учётные данные | Негативный | Клиент получает отказ аутентификации, не отправляет векторы и сообщает об ошибке. |
| 12 | Корректные данные и учётные данные, один вектор | Позитивный | Вектор передаётся серверу; полученный результат записывается в текстовый файл. |
| 13 | Корректные данные и учётные данные, несколько векторов | Позитивный | Передаются все векторы; в выходном файле указано количество результатов и сами результаты в требуемом формате. |
| 14 | Пустой набор векторов в корректном входном файле | Позитивный | Клиент корректно обрабатывает нулевое количество векторов и создаёт файл результатов согласно формату задания. |
| 15 | Выходной файл недоступен для записи | Негативный | Выводится сообщение об ошибке создания или записи файла; программа завершается с ошибкой. |

## Запись результатов проверки

Для каждого сценария записать:

- фактическое сообщение программы;
- фактический код завершения;
- содержимое выходного файла, если он создавался;
- итог: пройден или не пройден.
