# Программная реализация сетевого клиента

Курсовая работа по дисциплине «Технологии и методы программирования».

Реализуется клиентская программа для Linux на C++.

## Требования проекта

- TCP-соединение с сервером;
- аутентификация с SHA-256 и солью, формируемой клиентом;
- чтение числовых векторов из двоичного файла;
- передача векторов серверу и получение результатов;
- сохранение результатов в текстовый файл.
