# Программная реализация сетевого клиента

Курсовая работа по дисциплине «Технологии и методы программирования».

Клиентская программа для Linux на C++17. Подключается к TCP-серверу, выполняет аутентификацию, передаёт числовые векторы и сохраняет полученные результаты в текстовый файл.

## Возможности

- TCP-соединение с сервером;
- аутентификация с использованием SHA-256 и соли;
- чтение числовых векторов из двоичного файла;
- передача векторов серверу и получение результатов;
- запись результатов в текстовый файл;
- модульные тесты с использованием CTest.

## Требования

- Linux;
- компилятор с поддержкой C++17;
- CMake;
- Crypto++.

В Ubuntu необходимые инструменты можно установить командой:

```bash
sudo apt update
sudo apt install build-essential cmake libcrypto++-dev
```

## Сборка и запуск тестов

Выполните команды из терминала:

```bash
cd ~/Desktop/vclient-coursework
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build
ctest --test-dir build --output-on-failure
```

Тесты проверяют аутентификацию, параметры командной строки, файловый ввод-вывод и чтение учётных данных.

## Параметры командной строки

| Параметр | Краткая форма | Описание |
|---|---|---|
| `--address` | `-a` | Адрес TCP-сервера |
| `--input` | `-i` | Путь к входному двоичному файлу |
| `--output` | `-o` | Путь к файлу результатов |
| `--port` | `-p` | Порт сервера, по умолчанию `33333` |
| `--credentials` | `-c` | Путь к файлу учётных данных, по умолчанию `~/.config/vclient.conf` |
| `--help` | `-h` | Показать справку |

Для работы клиента необходим доступный TCP-сервер, совместимый с протоколом проекта, и корректные учётные данные.

## Файл учётных данных

По умолчанию используется файл `~/.config/vclient.conf`. Первая строка файла должна иметь формат:

```text
LOGIN:PASSWORD
```

Например:

```text
test_user:test_password
```

## Форматы данных

Входной файл содержит число векторов типа `uint32_t`. Для каждого вектора записаны его размер типа `uint32_t` и элементы типа `double`.

Файл результатов содержит количество результатов и сами значения, разделённые пробелами.

## Структура проекта

- `include/` — заголовочные файлы;
- `src/` — исходный код клиента;
- `tests/` — модульные тесты;
- `CMakeLists.txt` — конфигурация сборки и тестирования.
